# Credit-Risk-Default-Prediction-Model
– Data Source & Problem: Analyzed 100k+ Kaggle banking records to identify key loan default risk drivers.
– Methodology: Built Logistic Regression in Python (statsmodels) using WOE, IV, and VIF checks.
– Results & Impact: Achieved 0.82 ROC-AUC; optimized credit risk thresholds via precision-recall tradeoff.
